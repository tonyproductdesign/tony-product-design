Tony PRODUCT DESIGN - owner-managed product images

1. Place images here or in subfolders.
2. Use "assets/products/your-file.webp" in public/data/projects.json.
3. Do not include "public/" in image values.
4. HTTPS image URLs are also supported, including gallery and hero fields.
5. Rename a file -> update every JSON reference -> validate -> rebuild -> deploy.
6. npm run images prints copyable JSON values and production URLs.

Allowed local formats: .avif .webp .png .jpg .jpeg .gif .svg
Suggested names: lowercase ASCII, hyphens, meaningful product/view names.
Existing images/ paths remain valid for backward compatibility.
